Hello! I work on tools for verifying software and teach students and developers techniques for verifying software.

I work at [Antithesis](https://antithesis.com) on the universal property-based testing library [Hegel](https://hegel.dev), specifically [Hegel for O(x)Caml](https://hegel.dev/ocaml). 

My academic background is in property-based testing. I co-authored a DBTest 2026 workshop [paper](https://lemonidas.github.io/pdf/DIRT.pdf) on database testing and wrote my master's [thesis](https://api.drum.lib.umd.edu/server/api/core/bitstreams/8425d7be-a500-4598-85f6-1b888712bbb3/content) on automatically synthesizing stateful property-based tests from specifications in [CN](https://github.com/rems-project/cn). I obtained a Master of Science in CS from the University of Maryland, College Park, advised by [Dr. Leonidas Lampropoulos](https://lemonidas.github.io).
